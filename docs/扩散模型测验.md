## A 组逐题

### A1 —— 1/2，分类错、机制对

- ✅ **对**：扩散依赖马尔可夫链状态转移，VAE 是单步变分 —— 这正是根本机制差别。
- ❌ **错**：扩散是**显式密度**模型，不是隐式密度。GAN 才是隐式密度。

正确路径（`扩散模型学习指南.md` §1.1、`DiffusionModel_知识整合.md` §3）：

```
显式密度 → 近似密度 → 马尔可夫链 → 扩散模型（间接采样）
```

"显式"= 它真的定义并优化 $p_\theta(x)$，只是用 ELBO 近似而非精确计算。与 Boltzmann Machine 同格。

> ⚠️ 为什么重要：Day 3 训练目标的推导起点就是"扩散在优化显式似然的变分下界"。归到隐式密度，ELBO 那套推导就失去落脚点。

### A2 —— 0/2，两个问题

- ❌ **问题一**：把"无需学习"等同于"确定"。前向过程**是随机的**（给定 $x_{t-1}$，$x_t$ 每次采样都不同）。
  **正确判据**：前向没有待优化参数（$\beta_t$ 是人工设定的超参数）；反向的 $q(x_{t-1}\mid x_t)$ 不 tractable，只能用网络近似。
- ❌❌ **问题二（严重）**：反向过程**不参考 $x_0$**。若生成时能看到干净图，生成任务本身就不存在了。

| | 用到 $x_0$? | 用途 |
|---|---|---|
| 后验 $q(x_{t-1}\mid x_t, x_0)$ | ✅ 用 | **只在训练时**当监督信号 |
| 反向 $p_\theta(x_{t-1}\mid x_t)$ | ❌ 不用 | **生成时**真正跑的 |

训练时**故意**引入 $x_0$，是因为不含 $x_0$ 的 $q(x_{t-1}\mid x_t)$ 没有闭式解（见 `扩散模型课件小结_大工与ZhangXin.md` §3.2）。

> 🎯 **本组最该记住的**：$x_0$ 是**训练期的监督信号**，不是**推理期的输入**。

### A3 —— 1.5/2，数值对、定义反

- ❌ 定义说反：$\bar\alpha_t$ 是**信号保留系数**，不是噪声水平。

$$x_t = \underbrace{\sqrt{\bar\alpha_t}}_{\text{信号系数}}\cdot x_0 + \underbrace{\sqrt{1-\bar\alpha_t}}_{\text{噪声系数}}\cdot\varepsilon$$

- $\bar\alpha_t$（无根号）= 信号保留的**方差**比例
- $\sqrt{\bar\alpha_t}$ = 信号保留的**幅度**比例
- $1-\bar\alpha_t$ = **噪声**的方差比例 ← 你说的"噪声水平"其实是这个

$\bar\alpha_t\to 0$ = 信号没了；$\bar\alpha_t=1$ = 信号完好。**方向与你的描述相反。**

- ✅ 数值对。精确表述：信号幅度 $\sqrt{0.01}=0.1$，噪声幅度 $\sqrt{0.99}\approx0.995$ —— 噪声是信号的近 10 倍。

**自检技巧（建议记住）**：

$$\left(\sqrt{\bar\alpha_t}\right)^2 + \left(\sqrt{1-\bar\alpha_t}\right)^2 = \bar\alpha_t + (1-\bar\alpha_t) = 1$$

系数平方和恒为 1 → 这叫**方差保持（Variance Preserving, VP）**，即广义扩散框架里的 `VP: a=sqrt(abar_t), b=sqrt(1-abar_t)`。

### A4 —— 0/2，最需修的一题

- ❌ 答成了"怎么去噪"，而题目问"**为什么两种预测等价**"。且写出的递推式不存在。

纠正：从 $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\varepsilon$ 反解 **$x_0$**：

$$x_0 = \frac{x_t - \sqrt{1-\bar\alpha_t}\,\varepsilon}{\sqrt{\bar\alpha_t}}$$

对比所写 $x_{t-1} = x_t - \varepsilon_{t-1}$：**分母漏 $\sqrt{\bar\alpha_t}$**，**噪声项漏系数 $\sqrt{1-\bar\alpha_t}$**。

另注意区分两个式子（其中 $\varepsilon$ 含义不同，勿混）：

$$x_0 = \frac{x_t-\sqrt{1-\bar\alpha_t}\,\varepsilon}{\sqrt{\bar\alpha_t}} \qquad\text{vs}\qquad x_{t-1} = \frac{x_t - \sqrt{\beta_t}\,\varepsilon}{\sqrt{1-\beta_t}}$$

- ✅ **标准答案**：$x_t$ **已知**时，$x_0$ 与 $\varepsilon$ 通过核心式子**一一对应** —— 知道一个即可解出另一个。故"预测 $\varepsilon$"与"预测 $x_0$"是**同一问题的两种参数化**，信息等价，仅输出数值范围不同。（`扩散模型背诵卡.md` T4）

> 💡 直觉方向没错，但不精确。扩散不是"减去噪声"，而是**预测噪声 → 反解 $x_0$ → 用后验公式重新采样 $x_{t-1}$** 三步。

## B5 / B6

### B5 —— ✅ 3/3 全对

$$q(x_t\mid x_{t-1}) = \mathcal{N}\!\left(x_t;\ \sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\right)$$

因 $\alpha_t = 1-\beta_t$，也等价写作 $\sqrt{\alpha_t}\,x_{t-1}$。两种写法资料里都有（§2.2 vs 课件小结 §3.1），看到不必困惑。

### B6 —— ❌ 0/3 没答到

所写的是**单步**式子（条件在 $x_{t-1}$），题目要的是**条件在 $x_0$** 的闭式解。且 $\sqrt{\beta_{t-1}}$ 应为 $\sqrt{\beta_t}$（同一步，不跨步）。

正确：

$$q(x_t\mid x_0) = \mathcal{N}\!\left(x_t;\ \sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)I\right)$$

$$\Longleftrightarrow\quad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon$$
