## 2. `gaussian_diffusion.py` 五个 TODO 的参考实现

### 2.1 `q_sample` —— 前向过程 Eq.(4)

```python
def q_sample(self, x_start, t, noise):
    return (
        extract(self.sqrt_alphas_cumprod, t, x_start.shape) * x_start
        + extract(self.sqrt_one_minus_alphas_cumprod, t, x_start.shape) * noise
    )
```

对应公式：

$$
x_t = \sqrt{\bar{\alpha}_t}\cdot x_0 + \sqrt{1-\bar{\alpha}_t}\cdot \varepsilon
$$

### 2.2 `predict_start_from_noise` —— 反解 x_0

```python
def predict_start_from_noise(self, x_t, t, noise):
    return (
        extract(self.sqrt_recip_alphas_cumprod, t, x_t.shape) * x_t
        - extract(self.sqrt_recipm1_alphas_cumprod, t, x_t.shape) * noise
    )
```

对应公式：

$$
x_0 = \frac{x_t-\sqrt{1-\bar\alpha_t}\,\varepsilon}{\sqrt{\bar\alpha_t}}
$$

即

$$
x_0 = \frac{x_t}{\sqrt{\bar\alpha_t}}-\sqrt{\frac{1}{\bar\alpha_t}-1}\,\varepsilon
$$

，所以需要两个倒数系数：

```python
register_buffer("sqrt_recip_alphas_cumprod", torch.sqrt(1.0 / alphas_cumprod))
register_buffer("sqrt_recipm1_alphas_cumprod", torch.sqrt(1.0 / alphas_cumprod - 1))
```

> ⚠️ **重要**：这两个 buffer 在官方 `gaussian_diffusion.py` 里是**被注释掉的**（第 55–58 行）！
> 因为它们对应 DDPM 论文 Eq.(15) 的写法，而作业走的是 Eq.(6) 后验路径。
> **但 `predict_start_from_noise` 仍然需要它们** —— 你要么取消注释，要么在函数里现算。
> 这是最容易卡住的地方：`__init__` 里没注册，函数里却要用。

### 2.3 `predict_noise_from_start` —— 反解 ε

```python
def predict_noise_from_start(self, x_t, t, x_start):
    return (
        x_t - extract(self.sqrt_alphas_cumprod, t, x_t.shape) * x_start
    ) / extract(self.sqrt_one_minus_alphas_cumprod, t, x_t.shape)
```

对应公式：

$$
\varepsilon = \frac{x_t-\sqrt{\bar\alpha_t}\,x_0}{\sqrt{1-\bar\alpha_t}}
$$

> 注意：官方 docstring 写的是 *"Transform x_t and noise to get x_start"*，**是错的**。此函数接受 `x_start`、返回 `pred_noise`。

### 2.4 `p_losses` —— 训练目标 Eq.(14)

```python
def p_losses(self, x_start, model_kwargs={}):
    b, nts = x_start.shape[0], self.num_timesteps
    t = torch.randint(0, nts, (b,), device=x_start.device).long()
    x_start = self.normalize(x_start)
    noise = torch.randn_like(x_start)
    target = noise if self.objective == "pred_noise" else x_start
    loss_weight = extract(self.loss_weight, t, target.shape)

    # --- 需要你填的部分 ---
    x_t = self.q_sample(x_start, t, noise)
    model_out = self.model(x_t, t, model_kwargs=model_kwargs)
    loss = (loss_weight * (model_out - target) ** 2).mean()

    return loss
```

**三个关键点**：
1. `target` 按 `objective` 选（`pred_noise` → 噪声；`pred_x_start` → 干净图）
2. `normalize` 已在前面做好，**不要重复归一化**
3. `loss_weight` 两种 objective 不同（见 `__init__` 第 80–82 行）

**为什么 `objective="pred_x_start"` 时 loss 会高达 30**：x_start 的值域是 $[-1,1]$，而噪声是 `N(0,1)`；预测 x_start 的平方误差天然比预测噪声大一个量级，再乘上 SNR 权重（可远大于 1），得到 30 量级很正常。

### 2.5 `p_sample` —— 采样 Eq.(6)

```python
@torch.no_grad()
def p_sample(self, x_t, t: int, model_kwargs={}):
    t = torch.full((x_t.shape[0],), t, device=x_t.device, dtype=torch.long)

    # 1. 取模型预测
    model_out = self.model(x_t, t, model_kwargs=model_kwargs)

    # 2. 按 objective 统一到 x_start
    if self.objective == "pred_noise":
        x_start = self.predict_start_from_noise(x_t, t, model_out)
    else:
        x_start = model_out

    # 3. clamp 到有效范围（关键！）
    x_start.clamp_(-1.0, 1.0)

    # 4. 取后验均值与标准差，采样 x_{t-1}
    mean, std = self.q_posterior(x_start, x_t, t)
    noise = torch.randn_like(x_t)
    nonzero = (t != 0).float().reshape(-1, *((1,) * (x_t.dim() - 1)))
    return mean + nonzero * std * noise
```

**四个易错点**：
1. **必须 clamp `x_start` 到 $[-1,1]$**（因为 `normalize` 把像素映射到了 $[-1,1]$）。不加会累积误差导致生成崩坏。
2. 公式：

    $$
    t=0
    $$

    时不能加噪声（`nonzero` 掩码），否则最后一步又被加噪。
3. $t$ 要 `torch.full(...)` 展开成 `(b,)`，因为模型期望 batch 维度。
4. `self.objective` 两种都要处理 —— 测试 cell 22 两组都测。

### 3.3 `forward`（结构已确证，数值见 §4）

```python
def forward(self, x, time, model_kwargs={}):
    if "cfg_scale" in model_kwargs:
        return self.cfg_forward(x, time, model_kwargs)

    context = self.time_mlp(time)
    cond_emb = model_kwargs["text_emb"]
    if cond_emb is None:
        cond_emb = torch.zeros(x.shape[0], self.condition_dim, device=x.device)
    if self.training:
        mask = (torch.rand(cond_emb.shape[0]) > self.uncond_prob).float()
        mask = mask[:, None].to(cond_emb.device)
        cond_emb = cond_emb * mask
    context = context + self.condition_mlp(cond_emb)

    x = self.init_conv(x)

    # 1. 下采样，把每个 ResNet 的输出压栈（LIFO）
    skips = []
    for block1, block2, downsample in self.downs:
        x = block1(x, context=context);  skips.append(x)
        x = block2(x, context=context);  skips.append(x)
        x = downsample(x)

    # 2. 中间块
    x = self.mid_block1(x, context=context)
    x = self.mid_block2(x, context=context)

    # 3. 上采样，每次弹栈拼接
    for upsample, block1, block2 in self.ups:
        x = upsample(x)
        x = torch.cat([x, skips.pop()], dim=1);  x = block1(x, context=context)
        x = torch.cat([x, skips.pop()], dim=1);  x = block2(x, context=context)

    return self.final_conv(x)
```

**skip 连接必须用 LIFO 栈**：下采样把 4 个 stage 共 8 个特征图依次压栈，上采样逆序弹出。跨层级拼接（`layer1_block1` ↔ `layer4_block1`）正是 U-Net 的"U 形"结构。

### 3.4 `cfg_forward`

```python
def cfg_forward(self, x, time, model_kwargs={}):
    cfg_scale = model_kwargs.pop("cfg_scale")
    model_kwargs = copy.deepcopy(model_kwargs)

    eps_cond = self.forward(x, time, {**model_kwargs})
    eps_uncond = self.forward(x, time, {**model_kwargs, "text_emb": None})

    return (cfg_scale + 1) * eps_cond - cfg_scale * eps_uncond
```

**易错点**：`cfg_scale` 必须先从 `model_kwargs` 里 `pop` 掉，否则递归调用 `forward` 时会再次触发 `cfg_forward`（因为 `forward` 开头检查 `"cfg_scale" in model_kwargs`），造成无限递归。

## 4. ⚠️ 为什么 `Unet.forward`（cell 18）无法这样验证

我用 monkey-patch 的方式重建了 U-Net 的上/下采样块，结果：

- **cell 16 的 5 项断言全部通过**，包括 `num_params == 6499` 精确命中 → **结构完全正确**
- **cell 18 的数值对不上**（相对误差 1.0）

**原因不是实现错误，而是权重初始化顺序**：

cell 18 用了 `torch.manual_seed(231)`，然后依赖 **随机初始化产生的具体权重** 来比对输出。官方实现是在 `__init__` 的循环里**就地**创建 `downs`/`ups`；而 monkey-patch 是先让原 `__init__` 跑完（消耗掉 mid 块的随机数），再追加创建 `downs`/`ups`。**随机数的消耗顺序不同 ⇒ 权重数值不同 ⇒ 输出不同。**

由于默认初始化下网络输出本质上接近随机，期望值 30.0160 和 cell 18 的向量**只有用官方构建顺序才能复现**。

> **教训 / 对你实现的意义**：
> 1. cell 16 是**可靠的结构自检**（参数量 6499 + 通道列表），务必跑通。
> 2. cell 18 的数值对不上**不能直接说明你写错了** —— 先确认 cell 16 通过、且你的 `forward` 没有改动任何**已有层**的创建顺序。
> 3. 关键：**不要改变 `__init__` 中 `time_mlp`、`condition_mlp`、`mid_block1/2`、`final_conv` 的创建顺序**，只在原有的 `for` 循环位置就地填充 `down_block`/`up_block`。这正是作业注释反复强调 "exactly follow this structure ... in order to load a pretrained checkpoint" 的原因。
